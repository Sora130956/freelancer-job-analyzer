# Freelancer Job Analyzer — 产品需求文档

**版本：** 1.0（第 2.5 步 — 需求打磨版）
**日期：** 2026-08-19
**状态：** 待出验收标准（第 3 步）

---

## 1. 概述

### 1.1 一句话需求

一个 Web 应用，调用 Freelancer.com 官方 API，帮助 Python 爬虫方向的 freelancer 快速筛选值得投标的项目，同时作为作品集向潜在客户展示完整的 Python 数据工程技能链。

### 1.2 Who / What / Why

| 维度 | 说明 |
|------|------|
| **主用户** | 开发者本人 —— 浏览 Freelancer.com 上 Python 爬虫方向的项目，快速判断哪些值得投 |
| **次用户（作品集受众）** | Upwork 潜在客户 —— 通过打开链接即可使用的在线工具评估开发者技能 |
| **做什么** | FastAPI 后端 + 简洁前端；筛选 → 拉取 → 展示 → 导出 完整工作流 |
| **个人价值** | 省掉逐条手动判断；量化技术栈与市场需求的匹配程度 |
| **作品集价值** | 客户零摩擦体验真实工具；一站式展示 Python 爬虫 + FastAPI + pandas/openpyxl + 云部署技能链 |

## 2. 数据来源

- **API：** Freelancer.com 开发者 API — `GET /projects/0.1/projects/active/`
- **鉴权：** 只读查询匿名访问已验证可用，无需注册 OAuth 应用
- **限流：** 50 次/分钟，1000 次/小时
- **使用的关键字段：**

| 字段 | 用途 |
|------|------|
| `title`、`seo_url` | 展示标题 + 项目链接（`https://www.freelancer.com/projects/{seo_url}`） |
| `budget.minimum/maximum`、`currency.exchange_rate` | 预算 → 换算为 USD |
| `hourly_project_info.min/max_hourly_rate` | 时薪（类型为 hourly 时） |
| `bid_stats.bid_avg`、`bid_stats.bid_count` | 竞标均价、竞争人数 |
| `jobs[]`（需 `job_details=true`） | 技能标签 |
| `time_submitted` | 发布时间 |
| `type` | `fixed`（固定价）或 `hourly`（时薪） |

## 3. 查询 / 筛选面板

### 3.1 筛选字段

| 字段 | 类型 | 默认值 | 说明 |
|------|------|--------|------|
| 关键词 | 文本输入 | — | 对应 API 的 `query` 参数 |
| 技能标签 | 多选 + 模糊搜索 | — | 详见 §3.2 |
| 预算下限（USD） | 数字 | — | `min_price`（换算后） |
| 预算上限（USD） | 数字 | — | `max_price`（换算后） |
| 项目类型 | 单选：全部 / 固定价 / 时薪 | 全部 | |
| 发布时间 | 下拉：24小时内 / 3天内 / 7天内 / 30天内 / 不限 | 不限 | |
| 结果条数 | 数字输入 | 100 | 最大 500；步进 100 |

### 3.2 技能标签选择器

- 页面加载时，调用 `GET /projects/0.1/jobs/` 拉取全量技能标签并缓存到本地（会话级）。
- 渲染为可搜索多选框：用户输入文字可模糊过滤缓存的标签列表，点击选中。
- 已选标签以可删除的 chip 形式展示在输入框上方。
- 关键词搜索与标签选择**并存**，传给 API 时为 AND 逻辑。

## 4. 结果展示

### 4.1 摘要栏

```
找到 211 条，当前第 1 页 / 共 11 页  [< 1 2 3 … 11 >]   [下载 Excel]
```

### 4.2 结果表格

| 列名 | 数据来源 | 说明 |
|------|----------|------|
| 标题 | `title` + `seo_url` | 可点击链接 → `https://www.freelancer.com/projects/{seo_url}`（投标页） |
| 技能 | `jobs[].name` | 逗号分隔的 chip 展示 |
| 预算（USD） | `budget.*` × `exchange_rate` | 格式：`$50 – $150`（固定价）或 `$15/hr – $25/hr`（时薪） |
| 竞标均价（USD） | `bid_stats.bid_avg` × 汇率 | |
| 竞争人数 | `bid_stats.bid_count` | |
| 类型 | `type` | Badge：固定价 / 时薪 |
| 发布时间 | `time_submitted` | 相对时间："2 小时前" |
| 链接 | `seo_url` | 图标按钮 → 项目投标页 |

### 4.3 分页

- 默认每页 **20 条**（普通笔记本屏幕不需滚动）
- 用户可切换每页条数：10 / 20 / 50
- 所有已拉取结果缓存在内存中，分页为**客户端分页**（切页不重新请求 API）
- 每页条数选择器放在摘要栏内

### 4.4 空结果 / 错误状态

| 场景 | 展示方式 |
|------|----------|
| 无结果 | 居中提示："未找到相关项目，请尝试放宽关键词或筛选条件。" |
| API 报错 | Toast 通知显示 HTTP 状态码；结果区保留上一次数据（如有） |
| 实际返回量不足 | 摘要栏提示："API 实际返回 87 条，少于请求的 100 条" |

## 5. 页面可视化

渲染在结果表格下方，使用 **Chart.js**。

### 5.1 Top 10 技能柱状图

- X 轴：技能名称
- Y 轴：出现频次
- 仅展示当前结果集中频次最高的 10 个技能
- 标题："Top 10 Skills in Results"

### 5.2 预算分布直方图

- X 轴：USD 预算区间（如 $0–50、$50–150、$150–500、$500–1k、$1k+）
- Y 轴：项目数量
- 固定价和时薪项目用不同颜色区分（分组或堆叠柱状图）
- 标题："Budget Distribution (USD)"

每次执行新搜索后，两张图表自动更新。

## 6. Excel 导出

点击「下载 Excel」按钮触发，由 FastAPI 端点调用 **openpyxl** 生成并返回文件。

### Sheet 1 — Jobs List（项目列表）

包含本次请求拉取的**全部结果**（最多 500 条），不受页面分页限制。

| 列名 | 数据类型 | 说明 |
|------|----------|------|
| Title | string | |
| URL | string（超链接） | `https://www.freelancer.com/projects/{seo_url}` |
| Skills | string | 逗号分隔 |
| Budget Min (USD) | float | 保留 2 位小数 |
| Budget Max (USD) | float | |
| Avg Bid (USD) | float | |
| Competitors | integer | |
| Type | string | Fixed / Hourly |
| Currency (original) | string | 原始货币，如 INR、CAD |
| Posted At | datetime | ISO 8601 格式 |

排序规则：Budget Max (USD) 降序。

### Sheet 2 — Skills Frequency（技能频次）

完整技能频次统计（不限 Top 10，保留全部技能）。

| 列名 | 数据类型 |
|------|----------|
| Skill | string |
| Count | integer |
| % of Results | float（保留 1 位小数） |

排序规则：Count 降序。

### Sheet 3 — Budget Distribution（预算分布）

| 列名 | 数据类型 |
|------|----------|
| Budget Range (USD) | string |
| Fixed Count | integer |
| Hourly Count | integer |
| Total | integer |

分桶规则：`<$50`、`$50–150`、`$150–500`、`$500–1k`、`$1k–5k`、`>$5k`。

## 7. 后端 API 端点

| 方法 | 路径 | 说明 |
|------|------|------|
| `GET` | `/api/search` | 调用 Freelancer API；返回 JSON 结果 |
| `GET` | `/api/tags` | 拉取并缓存全量技能标签 |
| `POST` | `/api/export` | 接收结果 JSON；返回 `.xlsx` 文件 |
| `GET` | `/` | 提供前端 HTML |

## 8. 技术栈（作品集展示意图）

| 层次 | 选型 | 作品集信号 |
|------|------|-----------|
| 后端 | **FastAPI** | 现代异步 Python API 框架 |
| 数据处理 | **pandas** | 数据清洗、聚合、预算换算 |
| Excel 导出 | **openpyxl** | 多 Sheet Excel 生成 |
| HTTP 客户端 | **requests**（或 `httpx`） | API 集成 |
| 前端 | 原生 JS + **Chart.js** | 轻量无框架可视化 |
| 部署 | **Render** 免费套餐 | 提供可访问的 Demo 链接 |

## 9. 本期不做（Out of Scope）

- 用户登录 / 收藏搜索条件
- PeoplePerHour 作为第二数据源（规划 v2）
- 邮件提醒 / 定时爬取
- 移动端适配（桌面优先，作品集展示够用）

---

## 10. 约束条件

- 必须遵守 Freelancer API 限流：拉取 500 条 = 5 次请求，远低于 50 次/分钟上限
- Render 免费套餐：应用可能冷启动（约 30 秒延迟），作品集场景可接受
- 无需数据库：所有数据为每次搜索的临时会话数据
